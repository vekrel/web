# Vekrel brand

Vekrel = Vector Relay. The mark is two vectors meeting at one relay ring.

- `mark.svg`: logo mark, strokes use `currentColor`, ring is accent `#FF6A3D`.
- `mark-on-dark.svg` / `mark-on-light.svg`: fixed-color versions.
- `favicon.svg`: white mark on `#111111`.
- `logo-horizontal.svg` (currentColor, inline SVG only), `logo-horizontal-on-dark.svg`, `logo-horizontal-on-light.svg`: mark plus wordmark. Wordmark is live text (Nunito, falls back to system). Convert to outlines before print use.

Accent: `#FF6A3D`. Dark: `#111111`. Keep clear space of one ring width around the mark.
