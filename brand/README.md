# Vekrel brand

Vekrel = Vector Relay. Logo chosen 2026-10-22 (round 4, "M2 Tangerine": a mix of concepts C10 Always-on Box and C11 One Session).

The mark: an orange tile holding your always-on machine (graphite box) and your phone (cream plane), with one mint session bar running across both. The same live session, on whichever screen is in front of you.

| File | Use |
|---|---|
| `mark.svg`, `mark-512.png` | App icon, avatars, anywhere the symbol stands alone |
| `favicon.svg` | Browser tab |
| `org-avatar.svg`, `org-avatar-1024.png` | GitHub org and social avatars (full-bleed, platform crops corners) |
| `logo-horizontal-on-light.svg/.png` | README and docs headers on light backgrounds |
| `logo-horizontal-on-dark.svg/.png` | Headers on dark backgrounds |
| `logo-horizontal.svg` | Inline use; wordmark follows `currentColor` |
| `wordmark.svg` | Wordmark alone, `currentColor` |

Colors:

| Name | Hex |
|---|---|
| Tangerine (tile) | `#FF6A2B` |
| Graphite (machine) | `#24262B`, lid `#3B3E46` |
| Cream (phone) | `#FFF3E8`, overlap `#FFD9C2` |
| Session mint | `#5CFFB0` |
| Ink (wordmark on light) | `#1C1E22` |
| Paper (wordmark on dark) | `#F4F1EC` |

Wordmark: Avenir Next Bold, tracking -35/1000, outlined to paths (no font needed). Clear space: half the tile width on every side.

`archive-r1/` holds the first, retired mark. `concepts-r2/`, `concepts-r3/`, `concepts-r4/` hold the explorations.
