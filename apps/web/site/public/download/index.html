These early builds aren't signed yet. On macOS, open Vekrel once, then go to System Settings, Privacy & Security, and click "Open Anyway". On Windows, choose "More info", then "Run anyway".

Run agents on a server or an always-on machine with the CLI: npx vekrel connect. Or use rc.vekrel.com in your browser. All releases: github.com/vekrel/desktop/releases.

Nightly

Built every day from the latest code. Expect rough edges. Nightly installs next to the stable app as "Vekrel (Nightly)" and updates only to newer nightlies.

  • Desktop: nightly releases
  • CLI: npx vekrel@nightly connect
  • Web: rc-nightly.vekrel.com
